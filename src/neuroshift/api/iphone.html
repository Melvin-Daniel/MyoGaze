MyoGaze

iPhone

Safari plus Add to Home Screen. Install the profile first. Do not tap Visit Website.

  1. Tap Install certificate. Allow the download.
  2. Open Settings. Tap Profile Downloaded, then Install.
  3. Go to Settings → General → About → Certificate Trust Settings and enable MyoGaze LAN CA.
  4. Come back and tap Open MyoGaze (HTTPS). Allow the camera.
  5. Share → Add to Home Screen. Open MyoGaze from that icon next time.
